HTML Headings Explained

HTML headings organize the content of a webpage. They range from <h1>, the most important heading, to <h6>, the least important heading.

Select any example heading to focus on its level.

Heading Levels

01

H1: Main Page Heading

Use <h1> for the main heading of the page. A page usually has one clear <h1> describing its main topic.

02

H2: Major Section Heading

Use <h2> for major sections that belong under the page's main topic.

03

H3: Subsection Heading

Use <h3> for a subsection inside an <h2> section.

04

H4: Detailed Subsection

Use <h4> when a section needs another level of detail below an <h3> heading.

05
H5: Small Supporting Section

Use <h5> for a smaller supporting section beneath an <h4> heading.

06
H6: Lowest Heading Level

Use <h6> for the most specific heading level. It should appear inside a logical heading structure.

Important Rule

Choose headings according to their meaning and structure, not just their font size. CSS can change how any heading looks while keeping its proper semantic level.
